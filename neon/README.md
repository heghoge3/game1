# Neon Control

Веб-приложение для управления неоновой и LED-лентой по Bluetooth вместо Lotus Lantern / duoCo Strip.
Поддерживает контроллеры **ELK-BLEDOM**, ELK-BLEDOB, MELK и LEDBLE.

## Возможности
- Цветовой круг, яркость, тёплый/холодный белый, HEX, избранные цвета
- 14 «умных» эффектов (радуга, свеча, огонь, океан, сияние, полиция, сердцебиение, старая вывеска…) и 22 встроенных
- Светомузыка с микрофона телефона, 6 режимов
- Сцены: готовые и свои
- Таймер сна с плавным затуханием, будильник-рассвет, включение/выключение по расписанию
- Несколько лент одновременно, автопереподключение
- Порядок каналов (RGB/GRB/…) и коррекция белого
- Консоль для отправки сырых команд
- Устанавливается на главный экран (PWA)

## Запуск
Web Bluetooth работает только по **https** в Chrome на Android или в Chrome/Edge на ПК.
Опубликуй папку на GitHub Pages (Settings → Pages → Deploy from branch → `main` / root)
и открой ссылку в Chrome. Затем выбери в меню «Добавить на главный экран».

Перед подключением закрой китайское приложение: контроллер держит только одно соединение.

## Протокол (ELK-BLEDOM)
Запись в характеристику `fff3` сервиса `fff0`, по 9 байт:

| Команда | Байты |
|---|---|
| Вкл | `7e 00 04 f0 00 01 ff 00 ef` |
| Выкл | `7e 00 04 00 00 00 ff 00 ef` |
| Цвет | `7e 00 05 03 RR GG BB 00 ef` |
| Яркость 0–100 | `7e 00 01 VV 00 00 00 00 ef` |
| Эффект 0x87–0x9c | `7e 00 03 EE 03 00 00 00 ef` |
| Скорость 0–100 | `7e 00 02 VV 00 00 00 00 ef` |
